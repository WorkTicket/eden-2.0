# ADR-0001: Record architecture decisions

- **Status:** accepted
- **Date:** 2026-11-02

## Context
Many AI workers and humans will change this repo. Without a decision log, rationale is lost and contracts drift.

## Decision
Every decision affecting architecture, action space, persistence format, LLM interface, or the ethics policy gets a numbered file in `docs/adr/` using this template: Status, Date, Context, Decision, Consequences, Alternatives.

## Consequences
Slight overhead per decision; much easier handoffs. Copy this file as the template.
