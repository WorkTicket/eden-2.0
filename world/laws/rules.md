# Laws of Eden (intent, not implementation)

1. **Scarcity is mild, never lethal.** Hunger creates motivation, not death. (`mortality: false`)
2. **Fruit regrows.** Cooperation and sharing are possible but never forced.
3. **Locality.** You perceive only what is within `perception_radius`. Speech is heard by those nearby, one tick later.
4. **Consistency.** The world is deterministic given a seed. Nothing happens that the physics file does not explain.
5. **No leaks.** Nothing in-world text refers to the world as constructed. Observations are phrased as experience ("You walk east."), never as system messages.
6. **Persistence.** Objects and places stay where they were left. Memory only means something if the world remembers too.
